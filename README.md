# 马天驹 FM

以文件夹为核心的 Android 本地音频播放器，适合课程、录音、有声书和播客文件。

## 已实现

- 一个或多个文件夹的长期读取授权
- 递归扫描、目录路径保留、手动重新扫描
- MP3、M4A、AAC、WAV、FLAC、OGG、OPUS 识别
- 自然数字排序
- 后台、通知栏、锁屏及耳机媒体按键控制
- 音频焦点处理和拔出耳机自动暂停
- 独立播放进度、断点续播、最近播放和完成状态
- 播放速度、睡眠定时、收藏、书签和搜索
- 顺序、单曲循环、列表循环和随机播放
- 目录移出、排除后防止重扫恢复、已移出目录恢复
- 单个目录重新扫描、清除目录及子目录播放记录
- 使用头像照片作为桌面启动图标
- 首次安装自带一首本地试听音频，可由用户永久移除
- 三星等系统选择器只负责授予读取权限，App 内置目录浏览器负责实际选择
- App 内可逐层进入任意深度子目录，只有点击“确认添加并扫描”后才开始扫描
- 授权目录与实际扫描目录分开保存：可只添加 Movies 里的某一部小说，不会扫描整个 Movies
- 多个实际扫描目录可以共用同一个上级读取授权，移除后允许重新添加
- 总专辑按完整目录树统计；进入后可继续打开子文件夹，全部播放和合集搜索覆盖所有下级音频
- 支持按合集设置片头、片尾跳过秒数，片尾到点后自动播放下一集
- “上一首”始终直接切换到上一集，不再先重播当前音频
- 再次打开合集时自动滚动到该合集最近播放的音频；总专辑先定位到对应子文件夹
- 电话或微信录音临时打断播放后，重新获得音频焦点时自动继续；主动暂停和永久焦点丢失不会误恢复
- 底部迷你播放器改为两行高对比布局，完整提供上一首、后退 15 秒、播放、前进 15 秒和下一首
- 文件夹选择器从存储根目录打开；系统选择器提前返回目录时，仍不会触发扫描
- 已移出的子目录可以从原授权目录重新添加，成功后同步清除“已移出”记录
- 播放页按有声书场景重新布局：保留倍速、片头片尾、定时、上下集及前后 15 秒
- 播放页的“目录”会打开当前音频所在的实际子文件夹，并精确定位和高亮正在播放的这一集
- 播放页不再显示下载、收藏、书签、评论和模式切换，新播放队列固定为顺序播放
- 底部两行迷你播放器保留原布局和全部按钮
- 播放页下半部增加垂直间距；进度条改为独占整行、加粗并拉长
- 后退和前进 15 秒从进度条两侧移出，改为进度条下方的两个独立按钮
- 从播放页打开当前目录后，页面返回键和手机系统返回键都会回到刚才的播放界面
- 定时关闭改用放大的系统闹钟图标，开启后在图标下显示剩余分钟
- 倍速、片头片尾、后退 15 秒和前进 15 秒合并为一排四个等宽按钮，完整进度条放在其下方
- 定时按钮的文字字号和字重与目录、上一首、下一首保持一致
- 完整播放页的操作区整组贴近底部迷你播放器，便于单手操作
- 四个快捷按钮从左到右调整为：后退 15 秒、倍速、片头片尾、前进 15 秒
- 播放进度滑块改为固定 22dp 直径的正圆，不再纵向拉伸
- 定时按钮与目录、上一首、下一首使用相同尺寸，闹钟图标缩小为 18dp；定时开启后文字改为“剩余时间”
- 播放页顶部标题栏、集数卡、文件名和底部操作区重新分配垂直留白，屏幕空间均匀铺满
- 页面按安卓系统状态栏的实际高度自动增加顶部安全区，返回键、正在播放和本地标识不再与时间、电池和信号重叠
- 播放页的弹性留白分配到顶部、集数卡与标题之间，缩小文件名与快捷按钮之间的大块空白
- 定时按钮改用与目录、上一首、下一首相同的两行文字布局；开启后第二行显示实际剩余分钟
- 播放页移除左上角返回箭头和右上角无交互的“本地”标识，顶部只保留居中播放状态；系统侧滑返回仍然可用

## 构建

```bash
JAVA_HOME=/opt/homebrew/opt/openjdk@17 \
ANDROID_HOME="$PWD/.android-sdk" \
./gradlew clean assembleDebug lintDebug testDebugUnitTest
```

APK 输出在 `app/build/outputs/apk/debug/app-debug.apk`。

## 验证范围

当前版本已通过干净构建、Android Lint 和自然数字排序单元测试。由于构建机器没有连接安卓设备，文件授权、厂商后台限制、蓝牙耳机和锁屏控制仍需真机验证。
